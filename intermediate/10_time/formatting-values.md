# Layout component Values

<!-- ======================================================================= -->

| Meaning            | Layout Value | Example      |
| ------------------ | ------------ | ------------ |
| 4-digit Year       | `2006`       | `2026`       |
| 2-digit Year       | `06`         | `26`         |
| Month (01-12)      | `01`         | `06`         |
| Month (1-12)       | `1`          | `6`          |
| Month Name (short) | `Jan`        | `Jun`        |
| Month Name (full)  | `January`    | `June`       |
| Day (01-31)        | `02`         | `12`         |
| Day (1-31)         | `2`          | `12`         |
| Weekday (short)    | `Mon`        | `Fri`        |
| Weekday (full)     | `Monday`     | `Friday`     |
| Hour (24h, 00-23)  | `15`         | `17`         |
| Hour (12h, 01-12)  | `03`         | `05`         |
| Hour (12h, 1-12)   | `3`          | `5`          |
| Minute             | `04`         | `09`         |
| Second             | `05`         | `36`         |
| AM/PM              | `PM`         | `PM`         |
| am/pm              | `pm`         | `pm`         |
| Milliseconds       | `.000`       | `.608`       |
| Microseconds       | `.000000`    | `.608123`    |
| Nanoseconds        | `.000000000` | `.608123456` |

# Time parsing input Layout

<!-- ======================================================================= -->

| Input String                    | Layout                                     |
| ------------------------------- | ------------------------------------------ |
| `2026-06-12`                    | `time.DateOnly` or `"2006-01-02"`          |
| `2026/06/12`                    | `"2006/01/02"`                             |
| `12/06/2026`                    | `"02/01/2006"`                             |
| `06/12/2026`                    | `"01/02/2006"`                             |
| `2026-06-12 12:09:36`           | `time.DateTime` or `"2006-01-02 15:04:05"` |
| `2026-06-12 12:09 PM`           | `"2006-01-02 03:04 PM"`                    |
| `2026-06-12 12:09:36 PM`        | `"2006-01-02 03:04:05 PM"`                 |
| `2026-06-12T12:09:36Z`          | `time.RFC3339`                             |
| `2026-06-12T12:09:36.608Z`      | `time.RFC3339Nano`                         |
| `2026-06-12T12:09:36+05:30`     | `time.RFC3339`                             |
| `2026-06-12T12:09:36.608+05:30` | `time.RFC3339Nano`                         |
| `Jun 12 2026`                   | `"Jan 02 2006"`                            |
| `June 12, 2026`                 | `"January 02, 2006"`                       |
| `Fri Jun 12 12:09:36 IST 2026`  | `time.UnixDate`                            |

| Constant           | Actual Layout                           |

| `time.DateOnly`    | `"2006-01-02"`                          |
